# Nezona Properties Abuja

Landing page for Nezona Properties Ltd - real estate development and investment in Abuja (RC: 1767456).

**Live site:** https://nezona-properties-abuja-ef5310b79b.vercel.app

## About

A trust-first real estate landing page: navy-and-gold serif branding, floating hero image accents, estate and investment showcases, trust strip, FAQ accordion, news updates and an enquiry form.

## Features

- Full-height hero with floating image cards and trust stats
- Registered-company trust strip (RC: 1767456)
- Featured estate and land investment sections
- FAQ accordion and news/milestone cards
- Enquiry form wired to Supabase

## Stack

- HTML5 + Tailwind CSS (CDN)
- Vanilla JavaScript
- [Lucide](https://lucide.dev) icons
- Google Fonts
- Supabase Edge Function (contact form)
